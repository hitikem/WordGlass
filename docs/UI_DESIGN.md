# WordGlass UI 设计方案

- 版本：0.1（UI 原型）
- 风格：Apple Liquid Glass 的光学语言 + Premium Minimalism
- 色彩：蓝白主色，固定品牌色，不启用 Material You 动态取色
- 目标：先验证四页信息架构、学习体验和玻璃性能，再接入 Room/业务

---

## 1. 设计原则

1. **内容优先于材质**：玻璃只做空间层次，不盖住文字，不用低对比度白字。
2. **克制的液态感**：每屏最多 4–6 个真实玻璃表面；其余用半透明填充和细边框。
3. **一个视觉焦点**：首页是今日进度，背单词页是当前词卡，词库页是搜索与词条，我的页是身份与设置。
4. **不模仿 iOS 控件外形**：借鉴光学与动效，不复制系统控件，不接管 Android 返回/手势逻辑。
5. **中英双语层级**：英文单词与数字使用 Manrope，中文使用系统中文字体，避免字体缺字。
6. **性能是设计的一部分**：静态背景、限制模糊面积、长列表不进 AGSL、低端自动降级。

### 2.3 间距

`4 / 6 / 10 / 14 / 18 / 22 / 28 / 36 dp`

- 页面水平边距：20 dp
- 页面顶部：status bar + 10 dp
- 卡片内边距：18–22 dp
- 卡片间距：14–16 dp
- 底部导航预留：118 dp

### 2.4 圆角

| 类型 | 半径 |
|---|---|
| Chip | 14 dp |
| 小按钮/输入框 | 16–17 dp |
| 普通卡片 | 24 dp |
| 大卡片/导航 | 30 dp |
| Hero | 34 dp |
| 胶囊 | 50% |

玻璃表面使用 Prismal 连续曲率圆角；普通 Material 组件使用同一半径体系。

### 2.5 阴影

- 普通玻璃卡：10–14 dp，蓝色调、低透明度。
- Hero：18–20 dp。
- 悬浮导航：22 dp。
- 深色模式阴影更黑、更收敛，不制造“浮空塑料片”。
- 不使用纯黑大阴影；阴影只负责空间，不负责装饰。

### 2.6 动效

| 交互 | 时长/曲线 |
|---|---|
| 页面切换 | 420 ms 进入 / 180–300 ms 退出，ease-out |
| 卡片翻转 | 520 ms，FastOutSlowIn；cameraDistance 18×density |
| 导航指示器 | spring(damping 0.78, medium-low stiffness) |
| 按钮按压 | scale 0.975，spring snappy |
| 评级/选择反馈 | 180–260 ms 淡入 + 0.98 缩放 |
| 滑动回弹 | spring 0.78 |
| 滑出阈值 | 卡片宽度 25% |

所有动画使用 Compose Animation；系统“移除动画”时自动缩短/禁用。

## 3. 玻璃材质规范

### 3.1 分层

1. 背景：静态蓝白渐变 + 柔光球 + 极淡点阵。
2. 玻璃：Prismal backdrop 采样 → 模糊 → 边缘折射 → 表面颜色/色调。
3. 可读性层：半透明填充（Light 55–75%，Dark 60–80%）。
4. 边缘：0.8 dp 渐变高光 + 内阴影感。
5. 内容：高对比文字，独立于玻璃绘制。

### 3.2 使用范围

使用真实玻璃：

- 悬浮底部导航
- 首页 Hero、2×2 统计卡、待复习列表容器、周节奏卡、迷你操作卡
- 学习主卡、选择/听写提示卡、完成卡
- 词库搜索框/摘要卡/设置组

不使用真实玻璃：

- 长词库列表行（只使用半透明填充 + 边框）
- 每个设置行（只在组容器使用一层玻璃）
- 小图标按钮内部（用纯色/半透明圆形，避免嵌套玻璃）
- 键盘、系统对话框、Toast

### 3.3 可读性保护

- 玻璃表面必须有最低不透明度；文字不直接放在折射纹理上。
- 重要文字外层加轻微 scrim（同色低透明度），但不使用纯黑蒙层。
- 深色模式提高玻璃填充不透明度，避免背景亮斑穿透文字。
- 不在玻璃上使用细于 12 sp 的正文；标签最小 9–10 sp，仅用于辅助信息。

## 4. 四页设计

### 4.1 首页

目标：3 秒内知道“今天学了多少、还差多少、下一步做什么”。

结构：

```text
品牌 + 日期 + 问候 + 主题切换
┌─────────────────────────────┐
│ 今日学习      [12 DAYS]      │
│  ◯ 68%      17 / 25 词       │
│              还差 8 个词      │
│  [ 继续学习                  → ] │
└─────────────────────────────┘
[待复习 24] [已掌握 318]
[连续 12 天] [今日 38 分钟]
今日待复习                 查看全部
┌─────────────────────────────┐
│ E experience  10 min         │
│ P place       10 min         │
└─────────────────────────────┘
本周节奏                   3h 42m
┌─────────────────────────────┐
│ 比上周多学 18%               │
│  ▂ ▅ ▃ █ ▆ ▂ ▄              │
└─────────────────────────────┘
[错词本] [收藏夹]
```

关键：

- Hero 使用蓝色 Accent Glass，白字；其余为浅色玻璃。
- 统计卡不显示无来源的“增长百分比”，只显示原型数据集中的真实字段。
- “继续学习”进入背单词页；“查看全部”进入词库页。
- 空状态：没有学习记录时，Hero 改为“今天从 5 个词开始”，不显示 0% 进度环。

### 4.2 背单词

目标：让用户停留在卡片上，而不是菜单里。

顶部：

- 眉题 `SESSION 01 · CORE SET`
- 标题“背单词”
- 右侧组进度 `03 / 10` + 重新开始
- 四模式切换：卡片 / 滑动 / 选择 / 听写
- 细进度条

#### A. 卡片翻转

- 正面：`CORE 01` 胶囊、收藏、单词 42 sp、音标、发音圆钮、轻触提示。
- 背面：单词小标题、音标、释义、例句、翻译、熟词僻义、返回正面。
- 翻转：Y 轴 520 ms，内容在 90° 切换并反向旋转，避免镜像。
- 翻转后显示四档评价：不认识 / 模糊 / 认识 / 熟练；评价后进入下一个词。
- 背面内容可垂直滚动，避免小屏截断。

#### B. 左右滑动

- 卡片跟手位移 + 7° 倾斜，右滑出现绿色“认识”，左滑出现红色“不认识”。
- 超过卡片宽度 25% 触发；滑出 200 ms 后记录。
- 同时保留底部“不认识 / 认识”按钮，保证可发现性和无障碍。
- 支持撤销上一步。
- 卡片只显示单词、音标、发音和提示，不提前泄露释义。

#### C. 选择题

- 顶部提示卡：单词 + 音标 + 发音。
- 4 个选项，来自真实词库的其他释义；A/B/C/D 圆形标号。
- 选择后：正确项绿色高亮，错误项红色；显示正确答案；出现“下一题”。
- 选项不使用玻璃，使用低饱和填充；避免 4 层玻璃造成性能浪费。

#### D. 听写/拼写

- 两种模式：听音拼写 / 释义拼写。
- 听音：大发音钮 + “点击播放，听清发音”。
- 释义：中文释义 + “根据释义拼出英文”。
- 自定义玻璃输入框，居中大字号，Ascii 键盘，Done 提交。
- 检查后显示正确拼写、释义；错误时明确标红，不自动跳过。
- 原型使用系统 TTS，正式接入 Microsoft/Aliyun `SpeechService`。

完成态：

- 圆形成功图标、本组完成、认识/需巩固统计、“再练一组”。

### 4.3 复习词库

目标：快速找到词，而不是再做一套学习页。

结构：

- 标题 + 当前演示词数胶囊。
- 搜索框（词/中文释义）。
- 横向筛选：全部 / 待复习 / 学习中 / 已掌握 / 错词本 / 收藏。
- 摘要玻璃卡：词条数、目标 882、掌握进度、收藏数、筛选数。
- 排序：A–Z / 掌握度 / 最近。
- 词条行：首字母渐变徽章、单词、音标、释义、掌握标签、收藏。
- 点击词条打开底部详情：大单词、音标、播放、收藏、释义、例句、翻译、熟词僻义、0–5 掌握程度、开始复习。
- 空状态明确告诉用户如何恢复结果。

长列表行不使用 AGSL；滚动性能和可读性优先。

### 4.4 我的

目标：把学习设置和数据管理收进清晰分组。

结构：

- 标题“我的”
- 身份玻璃卡：渐变头像、Alex Chen、连续 12 天
- 三项统计：累计学习 / 已掌握 / 学习时长
- 学习：每日目标、自动播放
- 语音：发音人（女/男）、语速（0.8/0.9/1.0）、试听
- 外观：跟随系统 / 浅色 / 深色
- 数据与词库：导入词库、备份与恢复（原型阶段打开说明弹窗，明确未接入）
- 关于：版本、设计语言、开源许可
- 底部 `Made with care for focused learning.`

所有设置都有即时反馈；原型阶段不做持久化，正式阶段接 DataStore。

## 5. 导航与转场

- 四个顶级页面：首页、背单词、复习词库、我的。
- 悬浮玻璃导航栏：74 dp 磨砂条 + 92 dp 圆形液态透镜，左右 18 dp，避让手势导航。
- 选中项是 FlClash 风格的液态透镜：采样底栏内容层，产生边缘折射；可点击、可横向拖拽、松手吸附最近项。
- 透镜位置只更新 offset/图形层，避免拖拽时整页重组。
- 页面切换：淡入 + 水平 1/12 位移；退出更快，形成“进入更从容、离开更利落”的节奏。
- 二级路由（词条详情）使用底部 Sheet，不占底栏。
- 返回键遵循 Android 预测性返回；学习页内部状态不因切换标签丢失（后续接 ViewModel 持久化）。

## 6. 性能与降级

1. 背景静态，不做无限位移动画。
2. 当前每屏真实 AGSL 表面限制为 2 个：首页 Hero + 底栏透镜；其余卡片使用静态磨砂层。长列表行不入 AGSL。
3. Prismal 自动降级：API 33+ 全效果，31–32 只模糊，26–30 磨砂。
4. 低端设备/省电模式可把 `PrismalGlass.pipelineOverride` 降为 Standard/Legacy。
5. 不为每个列表项创建 `RenderEffect`。
6. 使用稳定 key 的 `LazyColumn`；搜索/筛选在 ViewModel 中完成。
7. 目标 60 FPS；首帧不阻塞；不在 draw 中 new Brush/Path。
8. 后续用 Macrobenchmark/Perfetto 验证滑动与页面切换。

---

## 7. 无障碍

- 触控目标 ≥ 44 dp；评级按钮高度 58 dp。
- 所有图标按钮有 contentDescription。
- 文字对比度 ≥ 4.5:1；不依赖颜色单独表达正确/错误，同时配合文字。
- 支持系统字体缩放；卡片背面允许滚动。
- 尊重系统“移除动画”；滑动同时提供显式按钮。
- 深色模式与浅色模式使用同一信息层级。
