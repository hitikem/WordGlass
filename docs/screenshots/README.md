The PNG files in this directory were captured during the **0.1 UI prototype** and are kept only
as a design history reference. They do **not** show the 0.2.0-beta Room data, the current
FlClash-style liquid-lens dock, backup/restore, or the final visual state.

Do not use these images as acceptance evidence for 0.2.0-beta. New device screenshots must be
captured after the phone is reconnected and the APK is installed.
